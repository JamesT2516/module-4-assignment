About Me

Hi, I’m James Taljaard. I’m currently working through a front-end web development course and using this portfolio to put what I learn into practice.

I started with the foundations of HTML and have since moved into CSS, responsive design, and more advanced layout techniques. Building this portfolio step by step has helped me understand how structure, styling, accessibility, and responsiveness all work together to create a better website.

What I Am Learning

Building on the Foundations

I started by learning how HTML gives a webpage clear and meaningful structure. I then moved into CSS and learned how colour, typography, spacing, and layout can improve the way a website looks and feels.

I am now learning how to build responsive layouts that adapt across different screen sizes using mobile-first design, media queries, Flexbox, and CSS Grid.

Skills I’m Building

  • Creating structured webpages with semantic HTML5
  • Styling webpages with external CSS
  • Working with colour, typography, and the CSS Box Model
  • Building layouts with Flexbox and CSS Grid
  • Using media queries and mobile-first responsive design
  • Creating responsive navigation and custom list styles
  • Adding transitions and clear focus states for interaction
  • Using Git and GitHub to manage and track my work
  • Validating HTML and CSS and correcting errors

My Projects

My First Portfolio Website

This portfolio is my first ongoing project for the Front-end Web Development course. It began as a simple semantic HTML page before I added CSS to improve the colour, typography, spacing, and overall layout.

I am now developing the site into a responsive portfolio using a mobile-first approach, media queries, Flexbox, CSS Grid, custom navigation, and transitions so that it works well across mobile, tablet, and desktop screens.

As I continue through the course, I’ll keep building on this project and applying the new skills I learn.
